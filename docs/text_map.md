## 제어 코드 (스크립트)

| 바이트 | 토큰 | 의미 |
|---|---|---|
| `01 xx` | `{c:xx}` | 글자색. 08 = 기본, 02·03·04·05·09·0a·0b 관찰 |
| `02 xx` | `{n:xx}` | 이름 변수 01–07. 01 = 주인공(이름 입력 가능) 추정, 02–07 = 파티원 추정 → 실행 파일 이름 목록과 대조 필요 |
