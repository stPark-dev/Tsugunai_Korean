- 데이터 파일 7종은 형식을 전수 해석: 원본 왕복 바이트 일치, 레코드 수 고정 테스트(`tests/test_datafile.py`, `tests/test_data_text.py`). 합계 804행, 고유 587개, 약 7,000자.
- 길이가 늘면 레코드를 뒤로 다시 배치하고 오프셋 표를 고친다. 파일이 커져도 게임이 읽는지(버퍼 크기)는 실행 확인 필요.
- SHOP/*.DAT 는 아이템 번호 목록·정련 표로 문자열 없음.
- 실행 파일: 폰트 글자(+전각 공백 0x8140, 폰트에 글리프 없음)로만 된 NUL 종료 문자열 가운데 참조가 있는 것.
  참조 = 포인터 워드 / lui+addiu 쌍(레지스터 추적, 호출·branch-likely 지연 슬롯 반영) / 분기 경로용 되짚기(256명령, addiu·ori 만, 표시 `loose`).
  `.sdata` 문자열도 gp 상대가 아니라 lui+addiu 로 접근함. 오탐 2건(구조체 접근, bnel 지연 슬롯)을 테스트로 고정.
- 번역이 용량 안이면 제자리, 넘치면 디버그 문자열(`\n` 끝, 22개 760바이트) 자리로 옮기고 lo 만 고친다(lui 유지 → 같은 64KB 구간).
- `.data` 의 `レイス` 2곳(0x249fd0, 0x24c880)은 참조가 없어 제자리 전용. 기본 이름은 이 둘이 아니라 이름 표 0x25d008 (PoC4).
- 맵 모델(MDL)·ATB 등의 SJIS 적중은 바이너리 잡음으로 판정(표본 확인).

## 제어 코드 (스크립트)

| 바이트 | 토큰 | 의미 |
|---|---|---|
| `01 xx` | `{c:xx}` | 글자색. 08 = 기본, 02·03·04·05·09·0a·0b 관찰 |
| `02 xx` | `{n:xx}` | 이름 변수 01–07. 01 = 주인공(이름 입력 가능) 추정, 02–07 = 파티원 추정 → 실행 파일 이름 목록과 대조 필요 |
