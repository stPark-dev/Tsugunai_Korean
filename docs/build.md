# 제품 빌드 기록

## 2026-11-16 첫 제품 빌드(개발 정책)

- 명령: `python3 -m tools.build orig/tsugunai.bin build/tsugunai_ko.bin` (약 5초)
- 입력 정책: 개발/PoC. 상태가 `untranslated` 가 아닌 대사 줄 전부(모두 `reviewed`, 배포 자격 아님) → 매니페스트 `distribution: false`.
- 빌드가 막는 것(실패하면 이미지·매니페스트를 쓰지 않음): 원본 SHA1 불일치, 번역 기계 검사, 한글 음절 > 한자 슬롯,
  배정 안 된·인코딩할 수 없는 글자, 조사 3자 초과, 실행 파일 문자열 용량·참조, 디스크 계획 밖 섹터 변경.
  넣을 문자열에 한글에 내준 슬롯의 한자가 있어도 실패. 산출물은 임시 파일 → 모두 성공하면 이름 바꿈, 실패하면 이전 산출물도 지움(코드 리뷰 반영).
- 줄 폭 경고(22칸 초과, 25칸 이하) 157줄은 매니페스트 `width_warnings` 에 기록.
- 결과: 대사 43,728줄(미번역 562줄은 디버그 스크립트), 한글 1,066음절 / 한자 슬롯 1,385, 조사 쌍 12,
  바뀐 파일 419개(재배치 2: MQ83/M83_01, MQ91/M91_02). 같은 입력으로 다시 빌드해도 같은 SHA1.
- 기본 이름 7개는 용어집에서(레이스·이펨·라후르크·피세라·아슈고·나비·미미 — 미미는 G0504 로 새로 넣은 초안).
- 알려진 한계(매니페스트 `stale_kanji` 912줄): 원문 그대로 남은 줄 중 한글에 슬롯을 내준 한자를 쓰는 줄.
  - 디버그 스크립트 `*_99` 301줄(플레이어에게 안 보임).
  - 실행 파일 108줄, 데이터 파일 503줄(아이템 223, 소지품 122, 퀘스트 기록 66, 마법 54, 무기 20, 호부 11, 몬스터 7) → 번역 전이라 화면에서 깨짐.
- 실행 확인(PCSX2, `work/shots/build/`): 타이틀 → 첫 장면 대사(루이 승관) → 배 위 병사 대화(색 강조 정상) → 이름 입력(음절표·기본 이름 「레이스」)
  → **「레이스였던가．」** → 이어지는 대사(「레이븐」 하늘색 강조, 여러 줄). 첫 장면 이후(재배치된 두 파일 포함)는 아직 확인 안 함.
