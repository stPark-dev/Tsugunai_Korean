환경: PCSX2 v2.8.2 (flatpak, `--filesystem` 프로젝트 폴더 허용), BIOS scph39001, `tools/run.sh`(Xvfb :99) + `tools/xinput.py`.
원본 부팅: 타이틀까지 약 35초(-fastboot). Return → l(○) → 약 45초 뒤 첫 대사(M00_25 `ルイ僧官 / 何ということでしょう…`).

- 질문: FONT.BIN 글리프를 바꾸면 대사 창·화자 이름에 그대로 나오는가? FILEZ/ISO 갱신으로 옮긴 파일을 게임이 읽는가?
- 빌드: `python -m tools.build_poc1 orig/tsugunai.bin build/poc1.bin`
  글자 12개 글리프를 Noto Sans CJK KR Medium 20px로 교체 → SL00 재압축 284,518 B(원래 279,869 B) → 섹터 수 초과로 디스크 끝 재배치.
- 관찰: 첫 대사 창에 `루이승관 / 『무슨일이란슨말인가이…』` 표시(`work/shots/poc1_a.png`).
- 결론:
  - FONT.BIN 헤더 CLUT 알파 해석과 4bpp(상위 니블=왼쪽) 해석이 맞음.
  - 대사 본문과 화자 이름(op 0x38)이 같은 폰트를 씀.
  - 파일 재배치(FILEZ.DAT + ISO 디렉터리 + 볼륨 크기 갱신)를 게임이 그대로 따름.
  - `『』`는 텍스트에 없는데 화면에 나옴 → 엔진이 붙이는 것으로 추정(번역문에 넣지 않음, 추가 확인 필요).
- 아직 아님: 텍스트 길이 변경(PoC2), 메뉴·전투 등 다른 소비자의 폰트 경로.

## PoC2 — 스크립트 텍스트 길이 변경·재배치 (2026-11-12, 통과)

- 질문: SCP 텍스트를 늘려 레코드가 밀려도(컨테이너 길이, op 0x01 점프, 헤더 오프셋 갱신) 게임이 정상 진행하는가? 창 폭은?
- 빌드: `python -m tools.build_poc2 orig/tsugunai.bin build/poc2.bin` — M00_25 텍스트 30개 전부 늘림(2,676 → 2,896 B, 제자리)
  화자 이름 + `テスト`, 대사 + `ＡＢＣ`, `しかし……` → 전각 36자.
- 관찰(`work/shots/poc2_*.png`, `mp2.png`):
  - 장면 끝까지 진행, 카메라 전환·다음 장면 전환 정상 → 점프/헤더 재배치 정상.
  - 대사 창 폭은 페이지에서 가장 긴 줄에 맞춰 자동으로 늘어남. 한 페이지 = 화자 이름 + 대사 최대 3줄 관찰.
  - 36자 줄은 창이 화면 왼쪽 밖으로 넘어가 앞부분이 잘림 → **줄 폭 상한 존재**(정확한 값은 0x37 좌표와 함께 측정 필요).
  - 글자가 한 자씩 찍히는 타자 효과.
- 결론: SCP 재배치 방식(`tools/scp.py`) 채택. 번역 줄 길이 상한은 별도 측정해 빌드 검사로 강제한다.

## PoC3 — 대사 줄 폭 상한 (2026-11-12, 통과)

- 빌드: `python -m tools.build_poc3 orig/tsugunai.bin build/poc3.bin` (M00_25 대사 줄을 전각 25/26/27자, 반각 문자 줄로 교체)
- 관찰(`work/shots/p3*.png`):
  - 엔진이 화자 대사의 첫 줄 앞에 `『`, 마지막 줄 끝에 `』`를 붙이고, 둘째 줄부터 1칸 들여 씀.
  - op 0x37 x = 창 왼쪽 희망 위치. 오른쪽이 화면 끝(약 608px)을 넘으면 창을 왼쪽으로 밀고, 그래도 넘치면 왼쪽이 화면 밖으로 잘림.
  - `『` + 25자 + `』` = 27칸 → 다 보임. `『` + 27자 = 28칸 → 첫 글자 잘림. **상한 27칸.**
  - 반각 영숫자(0x21–0x7E)는 화면에 그려지지 않지만 창 폭 계산에는 들어감 → 번역문 사용 금지.
  - 반각 공백 1개 = 약 전각 1칸(정밀 측정 아님).
- 결론(빌드 검사 규칙 후보): 대사 한 줄 ≤ 25칸(괄호·들여쓰기 2칸 여유). 번역 목표는 22칸 이하.
- 미해결: 화자 없는 서술(괄호 없음)의 여유, 한 페이지 최대 줄 수(원문 최대 3줄 관찰), 공백 폭(한국어 띄어쓰기 비용 — 좁은 공백이 필요하면 코드 수정 필요).
