# 말투 기록 (번역 정본)

용어는 `text/glossary.jsonl`, 표기·문장부호 원칙은 `docs/decisions.md` D4–D6.
상태: 확정 = 사용자 승인 샘플(MQ00, D6)에서 쓰인 것 / 초안 = 원문 관찰로 정한 것(검수 때 바뀔 수 있음).

## 공통 규칙 (확정)

- 원문 한 줄 → 번역 한 줄. 줄 폭 목표 22칸, 한계 25칸. 줄을 넘기며 문장이 이어질 때 동사구 중간에서 끊지 않는다.
- 문장부호·숫자·영문자는 전각: ．，？！…～ ０-９ Ａ-Ｚ. 반각 공백은 띄어쓰기에 쓴다.
- 토큰 `{c:xx}` 색, `{n:xx}` 이름은 원문 그대로 둔다(위치는 한국어 어순에 맞게 옮겨도 됨). 색 구간 안에는 용어만 넣는다.
- 이름 변수 바로 뒤 조사는 `{n:01}{j:은/는}` 형태(받침 있을 때/없을 때). `{n:01} 씨`처럼 띄어 쓰면 토큰 불필요.
- 서술·조사 메시지: 해라체 "~다．" / 시스템 안내·질문: 합니다체 "~습니까？" / 시스템 선택지: "예", "아니요".
- 【】 강조 괄호, 『』 인용(비문·편지·일기), ” ” 는 원문대로 둔다.
- ブツブツ… → …중얼중얼… , ふぉふぉふぉ → 허허허 , 의성어·감탄사는 자연스러운 한국어로.
- アンタ·あなた·貴方 → 당신(존댓말 화자는 문맥상 생략 가능). 어른이 어린 피세라·이펨에게 쓰는 あなた·あんた → 너. オマエ → 너. 
- おじょうさん(피세라를 부를 때) → 아가씨.
- 선택지가 주인공(또는 빙의한 인물)의 대답이면 그 인물의 말투로 쓴다("알았어", "싫어", "맡을게"). 행동 선택지는 "~한다"("읽는다", "그만둔다", "건넨다") (D7).
- 앞 화자 이름이 남아 있지만 표지판·조사 문장인 줄은 서술(해라체)로 쓴다.
- 부부 사이의 オマエ·キミ·アナタ → 당신(아내가 남편을 부를 때는 "여보"도 가능).
- 아이들이 주인공을 부를 때: おにいちゃん → 형(남자아이)·오빠(여자아이), おじさん → 아저씨. 피세라를 부를 때 남자아이는 누나, 여자아이는 언니.
- 통일 표기: 心のすさみ → 황폐해진 마음, 座礁船 → 좌초선, ネコとり名人 → 고양이잡이 명인, キノコとり名人 → 버섯잡이 명인, 張り紙 → 벽보.
